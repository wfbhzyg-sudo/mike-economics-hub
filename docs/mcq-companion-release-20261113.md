# 选择题 PDF 与 Mike 伙伴更新

## 使用入口
- 教师工作台 → 作业 → 从 PDF 创建作业。上传题目 PDF，可另附答案 PDF。后台逐页识别，核对裁切区域、选项、答案出处并逐题确认后发布。
- 学生从原作业列表进入。原题为主、字母按钮作答，支持缩放、标记、排除、题号筛选、保存恢复、计时和交卷回执。
- 混合作业沿用图片 / PDF / 文字提交与既有批改流程；选择题按教师确认的答案确定性评分，分数仍需教师复核发布。
- 已有成绩档案、错题订正、鱼骨图和热力图沿用；选择题原题图片可在复核和订正中直接展开。
- 经济一页通、教师工作台、电子作业、Bookself、EconQuest 均接入 Mike 像素伙伴。点击提问，拖动可移动位置；对话输入区使用明确标题、白底边框和深色发送按钮。
- 伙伴提供经济学与平台帮助，测验状态由服务器判定且仅提供操作帮助。密钥不发给浏览器，页面引用需用户主动选择，聊天记录按账号隔离。

## 实施边界
- 单次 PDF 最多 20 页 / 20 MB，最多 40 道题；AI 识别结果须教师核对，不能视作无误的解析结果。
- 平台帮助依据内置说明和用户本次主动引用的页面文字；当前不会自动搜索全部教材、读取其他页面或学生档案。
- 选择题分析中可更正答案：先逐人预览成绩变化，确认后创建答案版本并批量产生待复核成绩。旧成绩保留，学生在教师重新发布前仍看到旧成绩；其他已发布编辑继续沿用版本规则。
- 像素人物是轻量静态资源，界面带可关闭的开合过渡，不包含完整角色动画集。
- 外部 Wolai 页面不注入伙伴。

## 验证
- 作业服务 60 项自动检查通过；核心平台完整回归 564 通过、13 跳过，新加跨站伙伴代理检查通过。
- 原作业隔离集成测试 11 项通过，覆盖原图片/PDF/文字提交与发布、权限、导出、订正、晚交和重交。
- 真实 DeepSeek 使用自建经济学样题：2 道题分别定位 PDF 第 1/2 页，答案 C/B 指向第 3 页；发布至隔离测试班、恢复作答、私有答案拒绝访问、实际聊天均通过。
- Chrome 桌面与 390×844、320×720 视口检查：选择与缩放、题号、提交、教师原题联动、手机发布、跨站聊天历史、输入框与移动伙伴、减少动效。

- 作业数据库与核心账号数据库已加密备份，并在独立本地数据库恢复验证数据与结构一致。未迁移/删除数据库、卷、原件或原网址。
