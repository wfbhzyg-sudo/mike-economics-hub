# 作业中心 V3 — 2026-11-11

按已确认的 V3 设计更新学生作业中心和教师工作台。现有账号、班级、网址和数据库保持不变，不需要迁移数据。

## 主要变化

- 用紧凑任务行、窄侧栏和手机底部导航替换占据内容空间的菜单。按操作频率组织查看提交、编辑、布置作业和待处理事项。
- 用雾蓝、鼠尾草绿、灰紫、浅沙色区分任务、作答、批阅和异常；保留 navy 主操作按钮。长标题完整换行，手机输入控件保持可读字号。
- 学生可在题纸和作答间切换，保留 PDF 页码、缩放与文字。附件支持预览、排序、旋转、移除及单文件失败重试，提交前明确确认完整性。
- 教师可修改已发布作业的基本信息，修改题纸/答案后作为新版本发布；历史提交继续引用当时版本。参考答案可保存后返回上一步。
- 新作业表单支持当前浏览器暂存，进入参考答案步骤后保存到账户。逐题复核草稿私密保存，发布成绩另行确认。
- 支持复用作业为独立草稿、移入回收站和恢复。回收站不会物理删除作业、提交、成绩或附件；相关未完成批阅会暂停。
- 模型输出截断时进行一次精简重试；仍不完整的题目或评分点标记为待核对，保留其他完成结果，不将失败当成零分。

## 验证

- 主应用 28 项自动化测试、批阅工作进程 14 项测试通过。
- 独立数据库及合成账号执行 11 组提交/权限/持久化集成检查、5 组编辑/复核/回收站检查和 8 条浏览器操作流程。
- 11 个界面在 320、360、390、768、1024、1440 px 宽度检查，共 66 个界面组合；无页面横向溢出或 JavaScript 错误。
- 补充检查横屏、键盘、弹窗焦点恢复、减少动态效果模式、表单暂存恢复及畸形评分拒绝。
- 当前作业数据库已加密备份，恢复到独立数据库后核对内容和结构一致；没有恢复覆盖生产数据库。

手机检查使用 Chrome 视口及触控模拟，未替代实际 iPhone/Android 验收。模型恢复使用可控模拟响应测试，本次不声称完成真实模型批改准确率验证。

## 发布与恢复

部署现有 Railway production 的 portal 和云端 worker 服务；保留原网关和 URL。Mac 备用 worker 更新前备份原文件，并仅在空闲时重启。生产发布后核对精确提交号、服务 SUCCESS 状态、健康检查及未登录访问保护。

需要回退时将应用恢复到上一成功部署；本次没有破坏性数据库迁移。回收站通过应用内恢复，禁止通过数据库删除来清理作业。
