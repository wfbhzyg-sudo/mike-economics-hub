# AP Classroom MCQ end-to-end verification

Date: 2026-11-13. Environment: isolated local teacher, class and student accounts, using the configured real DeepSeek service. No production assignments, student grades or attachments were modified for testing.

## Actual source verification

- Supplied Unit 2 student booklet: 9 pages, 27 questions.
- Supplied scoring guide: 11 pages, 27 explicit answer keys.
- Final import: 27/27 keys match the independent scoring-guide transcription; 135/135 option texts match the selectable PDF text after whitespace/punctuation normalization.
- Every question's stem and options are contained in its resulting crop. Reviewed all 27 crop previews and the original-page renders.
- Questions 1 and 2 each retain the common elasticity table. Graph questions 11, 16 and 25 retain their diagrams. Tables in 13, 17 and 27 are complete.
- Original private question/answer PDF access is denied to students; published question images exclude scoring-guide content.

The supplied original booklet has no single question split across two pages. Cross-page verification therefore uses an explicitly labeled derivative of its question 11: original graph/stem/A–B on page 1; C–E on page 2; a separate next-question boundary. This does not modify the original PDFs. The final importer retains all five options, two correctly ordered image regions and answer B; the next question does not inherit the previous options. A published isolated attempt selecting B scores 1/1.

## Workflow results

1. Teacher uploads both real PDFs, imports, reviews and publishes 27 questions to an isolated class.
2. Student saves 26 answers, resumes the saved attempt in the browser and answers question 27.
3. The test intentionally answers questions 1, 2, 11, 16 and 25 incorrectly. Deterministic scoring produces 22/27, with no generated marking explanations.
4. The result stays in teacher review until explicitly released. The student's grade archive then shows 22/27 and exactly those five mistakes.
5. Student opens question 11 inline, zooms its diagram, selects B and edits the correction explanation. The correction stores both B and the explanation; original question score 0/1 and original total 22/27 are unchanged.
6. Common-material question 2 supports the two-part original through the same compact image page menu.
7. Student work and grade PDF exports are readable PDFs.

## Fixes

- Ground digital-PDF crop boundaries in numbered text coordinates instead of relying solely on model-estimated rectangles. Keep model regions as a reviewable fallback for scans/unrecognized layouts.
- Match explicit keys by unique original question number when running headers differ. Conflicting keys or ambiguous repeated section numbers remain ungraded until teacher confirmation.
- Merge continuation options rather than replacing previous-page options; preserve both halves of an option that itself spans pages.
- Exclude previous-page option fragments from the next question's shared material.
- Keep correction choice independent from the editable explanation while preserving compatibility with existing stored corrections.
- Show all original image fragments in the correction gallery page menu; add teacher analysis image enlargement.
- Add the new browser module to authenticated asset routing and a regression check for frontend module availability.

## Validation and limitations

- 71 automated regression checks pass.
- Chrome desktop (1280×900) and mobile viewport simulation (390×844); no claim of physical-phone testing.
- Two transient model format failures were recovered through the existing retry workflow; completed pages were retained. A missing empty keys array is now accepted without inventing a key.
- Teacher review and explicit confirmation remain required before publishing imported questions. This sample does not establish universal recognition accuracy for arbitrary scans, complex multi-column documents or every publisher layout.
- Fresh encrypted production database backup restored to a private local database: 2 tables, 36 rows, identical schema/data fingerprints and integrity checks passed. No migration or destructive data operation is part of this release.
