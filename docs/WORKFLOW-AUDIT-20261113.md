# 作业全流程审核与改进 · 2026-11-13

本次围绕教师发布与管理、学生作答与提交、后台评分、教师复核、成绩档案和错题订正审核。保留现有 navy 与低饱和纸面风格；把阅读和高频操作放在主要位置。测试写入均使用隔离账号和合成作业，不修改真实学生记录。

## 已修复的问题

| 优先级 | 原问题与影响 | 本次调整 |
|---|---|---|
| 高 | 混合作业多道简答题共用同一个文字和附件字段；填一题会让其他简答题也显示已答 | 文字、照片、PDF 按题号独立保存。交卷检查分别计数，提交时携带题号与附件页码对应关系 |
| 高 | 从旧版本继续作答，不能直接把共同答案分配给某道题 | 原共同文字与附件单独保留并说明；与新逐题答案一起提交，不丢弃、不猜题号 |
| 高 | 已发布选择题仍进入普通作业的题纸/参考答案编辑步骤，入口与作业类型不匹配 | 单独显示名称、日期、横向班级、补交/重交设置；更正选择题答案使用已有的预览重算流程 |
| 高 | 成绩页点击某道选择题“查看原题”，展示的是整份题纸与全部附件 | 定位当前提交版本的这道题及其所有图片片段，提供返回反馈和直接订正入口 |
| 中 | 断网/保存失败后只有提示，没有明确重试操作；本机存储失败仍可能显示“本机已存” | 新增重试保存；区分本机已保存与完全未保存；修复后清除过期错误提示 |
| 中 | 另一设备更新后，本机草稿版本不同，刷新时无法恢复 | 提供明确恢复选择，告知账户已经更新；选择恢复后再保存本机内容，不自动覆盖 |
| 中 | 每次输入都立即排队保存，快速输入产生多余请求 | 短暂合并连续输入，交卷前仍主动等待保存完成；本机草稿立即记录 |
| 中 | 教师题干、题号、答案出处等字段要失焦才更新草稿 | 输入时即更新草稿并自动保存，减少关闭或切换前的丢字风险 |
| 中 | 导入/生成题面尚未完成时离开，完成回调可能跳回旧流程或访问已移除控件 | 提前捕获提交内容；离开后任务继续，回调不再抢走当前页面 |
| 中 | 手机参考图片工具栏换行后高度不足，缩放按钮被裁掉 | 两行工具栏明确预留高度，主要触控按钮至少 44px；页码、缩放与更多操作保持统一 |
| 中 | 短题面套用整页照片高度，订正区前有大片空白 | 原题图片按比例决定高度，上限受视窗控制；重复题干文字折叠，保留随时放大能力 |
| 中 | 订正选项只有点击，缺少方向键切换和单一 Tab 焦点 | 与作答选项一致，方向键切换并选中，焦点与选中状态同步 |
| 低 | 纯选择题或纯简答题总分在分项栏重复显示；在线作答回执称“文字作答” | 仅混合题型显示分项得分，在线作答明确标注题数与已保存记录 |

## 组件与操作安排

### 教师端

- 已发布作业：名称与截止日期优先；班级为横向多选；补交、重交同区展示；保存结果紧邻保存按钮。
- PDF 核对：保留题面主区域、题号索引、答案核对栏。文本输入直接进入草稿，修改后取消对应题目的已核对状态。
- 答案更正：保留“预览影响 → 确认新版本 → 复核发布”，避免修改参考答案后悄悄重写已发布分数。
- 学生名单仍在对应作业内查看；保持已提交/未提交的文字与颜色提示，不把最近提交混入作业管理卡片。

### 学生端

- 选择题：题面优先，底部固定 ABCDE 与前后题操作；标记、排除、未答筛选继续可用。
- 混合简答：明确标注“第 X 题作答”，本题附件仅出现在本题。上传中不能交卷。
- 交卷：先展示未答和标记情况，允许返回对应题；保存完成后再提交。重复提交仍返回同一回执。
- 成绩：混合类型才拆分小计；失分题优先，原题使用提交时的快照，不跟随后来改题变化。
- 订正：桌面左右并排，手机上下紧邻；原题/原作答/历史记录同一区切换。题面文字默认折叠，保留相册、缩放和页码。
- 状态：区分保存中、本机待同步、账户已保存、已交卷、待教师确认和已出分；错误不能伪装成零分。

### 实际浏览器操作

- Chrome 桌面 1280×900，手机布局 390×844、窄屏 320×700。
- 合成综合作业：1 道选择 + 2 道简答。第二题填写后第三题仍为空，交卷检查显示未答 1 题；全部完成后显示未答 0 题。
- 返回、刷新后分别保留第二、第三题文字；模拟评分得到 4/7，待教师确认后发布。
- 成绩点击第三题原题，直接显示第三题；缩放 100% → 125% → 100%；选择题订正方向键选 B，说明与订正记录成功保存。
- 教师修改名称和补交安排后，题目版本仍为 v1、原成绩仍为 4/7。
- 320px 窄屏无整页横向溢出，订正图片工具按钮实测 44px 高。

这里的手机检查是浏览器视窗模拟，不是实体 iPhone/Android 的相机或软键盘测试。本次后台评分用受控模拟返回验证链路，不声称重新测定了 DeepSeek 的真实批阅准确率。上一轮实际 AP PDF 的识别验证结论不扩展为所有 PDF 都可自动准确切题。

## 后续值得继续做，但本次不冒充已完成

1. **教师多设备草稿冲突对比。** 当前保留版本冲突和本机草稿；可增加逐字段对比，让教师选择保留账户版或本机版，比简单刷新更可靠。
2. **导入质量检查清单。** 将低置信度答案、跨页题、共享图表、缺选项集中排队核对，优先呈现风险题。不要在未确认时自动发布。
3. **混合题逐题附件预览。** 当前已保留稳定的题号/附件页码关系，教师复核时可进一步按题号直接跳到对应学生照片页，减少翻页。
4. **差异化设置的班级变化提醒。** 更换布置班级时，明确提示已有个别学生延时规则是否仍适用，避免到发布时才发现不匹配。
5. **真实设备与弱网专项。** 用实体手机检查相机权限、键盘遮挡、前后台切换、连续拍照与断网重传；浏览器尺寸模拟不能替代这些验证。
6. **订正结果回看。** 保存后更显眼地展示“已保存的答案”摘要，让学生更容易确认上一轮订正，避免空的新编辑框被误解为内容丢失。

## 设计依据

保留用户已确认的题面优先、紧凑布局、低饱和分区、少重复信息、先给分再教师复核。交卷前允许检查和纠正的流程参考 [W3C 错误预防说明](https://www.w3.org/WAI/WCAG22/Understanding/error-prevention-legal-financial-data)；选项的方向键与 Tab 焦点行为参考 [WAI-ARIA Radio Group Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/radio/)。这些是具体交互参考，不等于宣称整站已经通过 WCAG 认证。

静态 UI 检测已人工复核：动态加载的教师原页图片不是缺失素材；现有低饱和颜色、圆角与字号提示来自较旧设计清单，本次保留已采用的视觉风格，没有为消除提示而重新换肤。
