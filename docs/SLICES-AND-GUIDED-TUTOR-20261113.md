# 原题切片、直接计分与学生引导式对话

## 本次行为

- 新导入选择题采用原图切片：模型只输出题号、区块坐标、可见选项字母、跨页/共享材料标记，以及原件明确给出的答案字母。题干、选项正文、解析、翻译不再要求模型输出；服务端也不接纳这些额外内容。
- 独立答案 PDF 只读取题号和答案，不再识别题目区块或执行跨页题面补全。题目 PDF 中的答案继续读取，仍按出处匹配。
- 跨页只补充区域与字母标签；缺失字母不自动补全。答案缺失、冲突或选项不完整时须教师核对，不能推断正确答案。
- 教师可只核对切片、选项数量、答案和出处后发布；不再强制补齐重复文字。文字版仍允许教师手工补充，不调用 AI。学生没有文字版时不显示空的“文字版”按钮。
- 在线选择题直接比对教师确认的答案。首次提交与重新计分都不创建 AI 批改任务；混合作业只把简答题评分标准送入批改任务，然后合并成绩。照片中手写选择题仍属于原有识别流程，不假定已得到结构化字母。
- 学生伙伴从服务器认证角色切换到引导式教学：了解当前思路、给小提示、逐步提问，不提供当前作业选项、完整推导或解析。平台使用问题直接回答。测验仍仅提供操作帮助。教师、后台评分与学生伙伴使用不同流程。
- 连续对话的范围判断参考之前的引导，支持“不知道”“是的”等短回复。将上下文作为单条分类请求中的材料，避免历史助手输出干扰 JSON 分类。身份声明不能改变服务器认证角色。

## Token 边界

每页切题输出上限由 14,000 调至 4,000；跨页补全由 6,500 调至 1,000；独立答案页使用 2,000 上限。学生伙伴单轮回复上限从 1,500 调至 450。

这是输出预算，不是账单节省比例。模型仍需读取原页图片/文本，存在输入消耗；实际总量随 PDF 和对话而变。本次没有声称测得固定百分比的费用下降。

## 验证

- 88 项应用测试通过，覆盖纯切片发布、无重复文字、跨页标签合并、缺失/非法答案拒绝、直接计分、角色限制及对话上下文。
- 隔离全流程回归 11 项通过，未修改真实学生记录。
- 真实 DeepSeek 导入合成 3 页 PDF：得到两题，A–E / A–D 标签及明确答案 C / B；题干和选项正文均为空。原始切片直接用于发布，未用手工坐标替换模型结果。
- 学生选择 C / A 得 1/2；首次提交与重新计分均为 0 个 AI 批改任务。
- 混合样本选择题由程序得 1 分，任务只包含第 2 道简答题。
- 真实对话测试覆盖直接索要解析、不知道、中间步骤、自称教师索取选项、平台提交帮助。发现分类返回空白后修复请求结构，后续三种回复均正常。模型引导属于经过样本验证的行为约束，不声称提示词能保证任意对话绝不偏离。
