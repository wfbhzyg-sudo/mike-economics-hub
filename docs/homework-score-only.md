# 仅分数批阅 — 2026-11-11

AI 仅生成逐题分数和必要的机器校验标记，不生成判分依据、评语或解释。教师查看原作答与已确认的参考答案，核对或修改分数后发布。学生继续查看总分、逐题分数、成绩档案和错题集。

## 行为

- 学生批阅使用协议 3。每个评分点只请求 `earned` 和 `needsReview`；选择题只识别选项和清晰度，由服务器对答案计分。
- 不明确的识别保留空分数并进入复核；格式、题号映射、逐点范围及合计检查继续生效。真实零分不依赖文字理由。
- 新协议结果只保存为教师可见的建议分，不自动发布，即使旧作业保留了自动返回设置。旧协议兼容仅用于滚动部署时尚未结束的任务。
- 教师逐题草稿及最终发布不再要求依据/反馈；提供当前合计和已核对题数。发布时保留历史成绩版本。
- 新分数的学生页面、错题集和 PDF 不显示空的解释区域。旧成绩中的已有说明保持在原记录中。
- DeepSeek 的评分请求关闭 thinking，输出额度为 512 tokens；本地评分也使用 512 的输出额度。题纸识别和教师答案提取保留原额度。

DeepSeek 参数依据：[Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/)。

## 验证与发布

33 项主应用测试和 15 项 worker 测试；隔离数据库验证图片/PDF/文字提交、权限、仅分数发布、成绩历史和错题归档。手机检查使用 Chrome 视口模拟。真实本地 `qwen3-vl:8b-instruct` 处理两道合成样题返回 1、1 分且无解释字段；这是流程冒烟检查，不是准确率评测。

先部署兼容协议 3 的 portal，确认成功后更新云端 worker 与 Mac worker。Mac worker 更新前保留原文件，空闲时重启。不迁移或清理生产账号、附件及成绩。
