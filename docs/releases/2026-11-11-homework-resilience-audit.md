## 参考与取舍

- [GOV.UK 文件上传](https://design-system.service.gov.uk/components/file-upload/)：上传成功、格式不符、失败重试应分清；保留可复用的已上传文件。沿用现有队列和恢复入口，新增提交前连续预览。
- [W3C 状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)：保存状态可被辅助技术感知，正常状态更新不抢走输入焦点。新增常驻保存状态，区分保存中、未保存成功和草稿已保存。
- [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog) 与 [GitHub Radix Primitives](https://github.com/radix-ui/primitives)：借鉴受控焦点、Escape 关闭、返回触发按钮的成熟弹层行为；继续使用项目现有原生 dialog，不新增 UI 框架。
- 结合上一轮已核实的 Google Classroom、Canvas、Carbon、GOV.UK 错误摘要与确认页，继续保留“选题纸—作答—确认提交—持久回执”和“进入具体作业再查看学生”的信息结构。

## 发现与已修复问题

| 优先级 | 真实问题 | 改善 |
| --- | --- | --- |
| 高 | 慢网保存参考答案时继续修改，服务器仅保留第一次快照；再次保存仍可能跳过最新内容。已在隔离环境复现。 | 串行保存，每个响应只确认对应修改；有后续输入时继续保存最新答案、题号、满分和评分点。失败保留页面输入，支持重试。 |
| 高 | 离开答案页后，延迟返回的保存回调可能读取新页面或清除新页面未保存提示。 | 保存使用原表单快照；旧页面回调不能清除新页面状态或把用户带回原页。 |
| 中 | 学生照片预览只有单张图片，检查清晰度与多页顺序需要反复开关。 | 同一附件列表共用连续相册；点击哪份文件就从哪份开始；支持缩放、拖动、整页/宽度、旋转预览、原件下载和页码跳转。 |
| 中 | 相册 PDF 目录只有文字占位。 | 打开目录时逐页生成实际缩略图；关闭或离开后停止并清理渲染任务，失败保留可点击的 PDF 占位。 |
| 中 | 答案保存操作藏在原件区域，保存状态主要靠短暂提示。 | 页首增加“保存草稿”和常驻状态。整理/发布请求发出后短暂锁定编辑控件，确保提交快照与正在处理的内容一致。 |
| 中 | 手机预览工具过密，关闭后可能失去操作位置。 | 手机使用全屏预览、两行底部工具和 44px 触控目标；关闭回到原按钮。Escape 先收起相册，再关闭预览。 |

预览旋转只改变查看角度；原文件、学生提交与教师评分不变。相册按需加载，PDF 缩略图仅在展开时渲染。教师仍使用以学生作答为主的 indicative score 复核界面。
