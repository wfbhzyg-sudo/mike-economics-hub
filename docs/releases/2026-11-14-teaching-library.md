# Teaching library, 14 November 2026

The classroom workspace uses one course tree and one content tab row. Teacher navigation prioritizes course packages, uploading assignments, and reviewing submissions. Existing routes remain available. Learning-focus text is English with translated key terms.

PDFs support authenticated byte ranges, short-lived document reuse, adjacent-page prefetch, stable page changes, and separate projection windows. Projection synchronizes only the slide page; background controls are inert. Textbook/answer annotations support positioned text as well as ink, revision conflicts, private drafts, and overflow-safe answer PDF export.

Question records are imported additively from original files. A verified revision can supersede a previous question in the picker without changing old assignment snapshots. Missing or uncertain answers, diagrams, scoring points, and boundaries remain pending and cannot be published. Multiple-choice scoring continues to compare confirmed keys without calling AI. Full-paper selections are not assigned a false Unit 1 learning classification. Papers above the existing 40-question assignment limit are presented as numbered parts.

Release evidence is stored in the project operations folder `operations/immersive-library-20261114`. Original materials and private account/grade backups are not included in the repository. Existing databases, data volumes, accounts, grades, assignments, object keys, and source files are retained.

Validation: unit tests, twelve-unit regression flows, 245 verified MCQ key comparisons through publish/submit/review/correction, PDF range authorization, private notes, conflict handling, multilingual PDF overflow, desktop Chrome projection, and mobile browser viewport workflows. Mobile checks are browser simulations, not physical-device tests.
