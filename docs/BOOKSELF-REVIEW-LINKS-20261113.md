# 错题直达 Bookself 章节

## 使用方式
学生在错题列表或展开订正后，点击「复习对应章节」。新标签页直达对应教材章节，沿用 Bookself 登录状态，原订正页面和草稿保留。

教师进入「作业与批阅 → 打开作业 → 复习章节」，可搜索教材或知识点，设置全卷通用章节，或逐题选择最多 3 个章节。先预览，确认后保存；清空逐题选择可取消该题的关联，恢复自动关联可重新沿用默认配置。

## 关联规则
优先级：教师逐题设置 → 全卷通用章节 → 已有知识点的精确匹配。使用生产 Bookself 的 7 本教材、198 个真实章节目录。图像题或没有可靠知识点的题目不猜测链接，显示待教师关联。不会调用 AI，不增加 token 消耗，也不重新生成题目或答案。

旧错题会读取新关联，无需重新批改。逐题关联包含题目内容指纹；题目被替换后不会误用旧映射。关联记录独立存储，不改变作业、提交、成绩或订正记录。只有该作业教师可修改，学生及其他教师无权操作；并发修改进行版本校验。
